# Evaluation fixtures

Only original, public-domain, permissively licensed, or non-musical numeric
fixtures may be added here. `online_amt_runtime` is the deterministic Task 01
runtime fixture: silence plus a synthesized 440 Hz harmonic signal and the
canonical model outputs derived from it.

Real recordings, MIDI annotations, exact copyrighted score sequences, and traces
derived from them belong in the private `piano-transcription-evals` repository.
